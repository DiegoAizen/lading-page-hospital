# Clínica Salud Integral - Landing Page

Landing page moderna y responsive para una clínica médica, construida con Next.js 14, TypeScript y Tailwind CSS.

## Características

- ✅ Diseño completamente responsive
- ✅ Página de inicio con secciones informativas
- ✅ Catálogo de servicios médicos
- ✅ Información de contacto y formulario
- ✅ Navegación suave entre secciones
- ✅ Diseño moderno y profesional
- ✅ Optimizado para SEO
- ✅ Código TypeScript tipado

## Tecnologías Utilizadas

- **Next.js 14** - Framework React con App Router
- **TypeScript** - Tipado estático
- **Tailwind CSS** - Framework de estilos
- **Lucide React** - Iconos
- **React** - Biblioteca UI
